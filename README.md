# Deadline Rescue

A student command center for deadlines, study resources, and task management.

Live site: https://deadline-rescue-chandra-1711.rightcabin512.chatgpt.site

## Features

- Student dashboard and deadline tracker
- Calendar and task completion
- Manual capture of pasted class-group messages
- Saved study resources
- Progress insights
- JSON backup and restore
- Responsive layout

## Run locally

Open `index.html` in a browser, or serve this directory with `python3 -m http.server 8000` and visit http://localhost:8000.

The app is self-contained HTML, CSS, and JavaScript. No build or installation is required. Data is saved in the current browser's local storage; it does not sync across devices. Message capture uses text you paste and does not automatically connect to WhatsApp.

## Hosting

This repository contains the website source copied from the published ChatGPT Site. GitHub commits are not automatically deployed to that Site; publication is managed separately in ChatGPT Sites.
